# Berdly — Dark World runtime sprites

Kristal actor path: `party/berdly/dark`

When original or otherwise authorized runtime-ready artwork is available, place it in this directory. Directional walking frames follow Kristal's numbered-frame pattern:

- `walk/down_1.png`, `walk/down_2.png`, …
- `walk/left_1.png`, `walk/left_2.png`, …
- `walk/right_1.png`, `walk/right_2.png`, …
- `walk/up_1.png`, `walk/up_2.png`, …

Keep frame dimensions and origin consistent within an animation. The actor currently inherits Kris's path as a safe fallback, so leave that fallback unchanged until the needed Berdly files are present and tested in Kristal.
