# W.D. Gaster sprites

The first in-game Gaster sprite is a 96×192 transparent PNG at `idle.png`.
It uses a tall monochrome silhouette, pale mask-like face, dark eye sockets,
black coat, and muted violet details.

The initial concept sheet included several poses; this commit wires the neutral
pose as the actor's default. Additional poses and battle animations can be mapped
once the base encounter is rendering correctly.
